**Notch Usage 0.6: your Claude limits on every display, without a fake notch.**

A milestone release that brings together everything since 0.5.5.

## Highlights

- **Displays without a notch.** On an external display or with the lid closed, the menu bar takes over:
  - **Menu bar icon**: a gauge, the time left before a block, and waiting Claude Code sessions.
  - **Centered capsule, optional**: the same information in a small capsule in the middle of the menu bar, with the panel just below it.
- **The detail follows you.** With an external display:
  - **On the Mac**, the island shows your usage right of the notch.
  - **On the other display**, the island fades away and the capsule takes over.
  - **Moving between them**, everything stretches and folds in one movement.
- **A detached panel.** Hovering the notch opens the panel in a card just below it, rounded on all four corners.
- **Update in one click.** *Settings → Check for updates* runs Homebrew in Terminal, or opens the releases page. The app itself still talks only to Anthropic.

## What's fixed since 0.5.9

- **Full screen read from macOS itself.** Full screen is now detected from what macOS shows on the display, not from the size of the front window. A maximized app no longer hides the island, even with desktop icons hidden.

## Updating

From 0.5.8 or later, use **Settings → Check for updates**. From an older version:

```bash
brew update && brew upgrade --cask notch-usage
```

## Install (preview build, not notarized)

With Homebrew:

```bash
brew install --cask florentmaille/tap/notch-usage
```

Already installed? `brew update && brew upgrade --cask notch-usage`. Otherwise:

1. Download `NotchUsage-0.6.0-preview.zip` below and unzip it.
2. Move **NotchUsage.app** to your Applications folder, replacing the previous version if you have one.
3. Open it. macOS says it cannot verify the developer: click **Done**.
4. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Notch Usage, then confirm.

Upgrading: macOS asks again for Keychain access. Click **Always Allow**.

## Known limitations

- The capsule needs a visible menu bar: with *Automatically hide and show the menu bar*, it does not show.
- On displays narrower than 1700 pt, the capsule is not shown, so it never covers app menus; the menu bar icon covers those displays.
- Not notarized: the Keychain may ask again after you replace the app with a newer build. Signed releases will fix this.
- Uses undocumented Anthropic endpoints that may change at any time. Read the [risk note](https://github.com/florentmaille/Notch-Usage#%EF%B8%8F-risk-note-please-read).

Requires macOS 14 (Sonoma) or later, Apple Silicon or Intel.
