**Fixes for a MacBook with an external display.**

## What's fixed

- **No more gap in the menu bar.** With *Menu bar icon* set to *Never*, an empty slot stayed between two icons. Notch Usage now follows the screen you work on from your clicks and app switches, with nothing in the menu bar and no new permission.
- **The island shows on hover.** Pointing at the notch while you work on the external display now shows the island above the panel, not just the panel.
- **Maximized windows are not full screen.** An app filling the MacBook's screen, such as a maximized Teams window, was taken for a full-screen app, which hid the island. Only real full-screen apps hide it now.

## Updating

From 0.5.8, use **Settings → Check for updates**. From an older version:

```bash
brew update && brew upgrade --cask notch-usage
```

## Install (preview build, not notarized)

With Homebrew:

```bash
brew install --cask florentmaille/tap/notch-usage
```

Already installed? `brew update && brew upgrade --cask notch-usage`. Otherwise:

1. Download `NotchUsage-0.5.9-preview.zip` below and unzip it.
2. Move **NotchUsage.app** to your Applications folder, replacing the previous version if you have one.
3. Open it. macOS says it cannot verify the developer: click **Done**.
4. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Notch Usage, then confirm.

Upgrading: macOS asks again for Keychain access. Click **Always Allow**.

**Checksum (SHA-256)** of the zip: `4ce03f74200451226d4d28c41029ffc5430a932a2b4988f899a0b15fe8dde9dd`

## Known limitations

- The capsule needs a visible menu bar: with *Automatically hide and show the menu bar*, it does not show.
- On displays narrower than 1700 pt, the capsule is not shown, so it never covers app menus; the menu bar icon covers those displays.
- Not notarized: the Keychain may ask again after you replace the app with a newer build. Signed releases will fix this.
- Uses undocumented Anthropic endpoints that may change at any time. Read the [risk note](https://github.com/florentmaille/Notch-Usage#%EF%B8%8F-risk-note-please-read).

Requires macOS 14 (Sonoma) or later, Apple Silicon or Intel.
