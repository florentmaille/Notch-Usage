**Renew an expired Claude Code session in one click.**

## What's new

- **Renew session.** When the Claude Code session has expired, the panel offers *Renew session*: Notch Usage asks your own `claude` command for a one-word reply (Haiku, one turn, no MCP servers, no user settings, nothing saved), which makes Claude Code renew its token, then reconnects. It only runs when you click, since the reply counts as a tiny request in your 5-hour window. Notch Usage still never refreshes the token itself.
- **Clearer network errors.** *No network connection*, *Claude did not answer in time* and *Could not reach Claude* are now told apart.
- Under the hood: the connection flows (Claude Code, browser, silent recovery, sign-out) are now covered by tests, and the app has its own test target in CI.

## Install (preview build, not notarized)

With Homebrew:

```bash
brew install --cask florentmaille/tap/notch-usage
```

Already installed? `brew upgrade --cask notch-usage`. Otherwise:

1. Download `NotchUsage-0.4.2-preview.zip` below and unzip it.
2. Move **NotchUsage.app** to your Applications folder, replacing the previous version if you have one.
3. Open it. macOS says it cannot verify the developer: click **Done**.
4. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Notch Usage, then confirm.

Upgrading: macOS asks again for Keychain access. Click **Always Allow**.

## Known limitations

- Not notarized: the Keychain may ask again after you replace the app with a newer build. Signed releases will fix this.
- The forecast covers the 5-hour window only; weekly limits use thresholds.
- Uses undocumented Anthropic endpoints that may change at any time. Read the [risk note](https://github.com/florentmaille/Notch-Usage#%EF%B8%8F-risk-note-please-read).

Requires macOS 14 (Sonoma) or later, Apple Silicon or Intel.
