**Follow your usage on an external display or with the lid closed, without a fake notch.**

## What's new

- **The island stays on the notch.** It shows on the built-in display, even when an external display is the main one. The black pill that imitated a notch on other displays is gone.
- **The menu bar takes over on displays without a notch.**
  - **What the item shows**: a gauge, plus the time left once a block is forecast (`2:05`, then `8′` in red), and the Claude Code glyph with a count when sessions wait.
  - **On the notched display**, the island already shows the detail, so the item shrinks to the gauge.
  - **Clicking**: click for the same panel as the island; right-click for *Refresh now*, *Settings* and *Quit*.
- **Centered capsule, optional.** On displays 1700 pt wide or more, a small dark capsule sits in the middle of the menu bar with the same information.
  - **Opening the panel**: push the pointer to the top of the screen above it and the panel opens just below the bar.
  - **On the notched display**, it shrinks to the gauge.
  - **In full-screen apps**, it hides, like the island.
  - Turn it on with **Centered capsule on wide screens** in Settings.
- **Menu bar icon: Automatic, Always or Never.** *Automatic* (the default) shows the icon while a display without a notch is connected. If you had turned the icon on, it is now *Always*.

## Install (preview build, not notarized)

With Homebrew:

```bash
brew install --cask florentmaille/tap/notch-usage
```

Already installed? `brew upgrade --cask notch-usage`. Otherwise:

1. Download `NotchUsage-0.5.6-preview.zip` below and unzip it.
2. Move **NotchUsage.app** to your Applications folder, replacing the previous version if you have one.
3. Open it. macOS says it cannot verify the developer: click **Done**.
4. Open **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to Notch Usage, then confirm.

Upgrading: macOS asks again for Keychain access. Click **Always Allow**.

**Checksum (SHA-256)** of the zip: `64e8ff4ebec60a1f72bd7dd58ea832adb53a630cea2878c974a17f5ef96d1fd3`

## Known limitations

- The capsule needs a visible menu bar: with *Automatically hide and show the menu bar*, it does not show.
- On displays narrower than 1700 pt, the capsule is not shown, so it never covers app menus; the menu bar icon covers those displays.
- Not notarized: the Keychain may ask again after you replace the app with a newer build. Signed releases will fix this.
- Uses undocumented Anthropic endpoints that may change at any time. Read the [risk note](https://github.com/florentmaille/Notch-Usage#%EF%B8%8F-risk-note-please-read).

Requires macOS 14 (Sonoma) or later, Apple Silicon or Intel.
